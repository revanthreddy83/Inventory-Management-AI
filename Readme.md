# 📦 Inventory Management using AI

## 📌 Overview
This project is an AI-based Inventory Management System that predicts future demand and helps in maintaining optimal stock levels.

## 🎯 Objective
To reduce overstocking and understocking using data-driven forecasting.

## 🚀 Features
- 📊 Demand Forecasting using ML
- 📦 Inventory Tracking
- 📈 Dashboard Visualization
- 🔄 Real-time Data Handling

## 🛠️ Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Machine Learning (ARIMA / XGBoost)
- Chart.js
